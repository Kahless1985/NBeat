Help

Rating: Tap +2, +1, 0, -1, or -2. If you rate before the Beat boundary, playback continues and that boundary will not pause. If you rate at the automatic boundary pause, playback resumes from that exact position without seeking.

Skip: leaves the Score unchanged and continues naturally. In Unrated Review Mode it seeks to the next unrated Beat.

Back: goes to the current navigation unit start, or the previous unit if already at its start. It preserves whether playback was playing or paused.

Forward / Beat End: in Beat mode it jumps to the current Beat pause point. If the Beat is already rated and audio was playing, it continues immediately into the next Beat; otherwise it remains paused at the boundary. In Scene/Sequence/Movement mode it jumps to the next unit and can bulk-score skipped Beats.

Files: Put one MP3 or MP4, one CSV, and one timing JSON in each book folder. Filenames do not need to match. Choose that folder and Beat Rater identifies the three files by extension. The fallback picker can select the same three files together.

Timing: Waveform-aware mode uses effective_stop_ms from your PC-generated .timings.json. Turning it off uses the CSV Stop_Time.

Backup: the top-right Backup indicator becomes prominent after 50 score changes or one hour with unexported changes. Tap it at any time to export the current CSV. Saving over the source CSV is the expected workflow.

Important on iPhone: keep Beat Rater in the foreground while relying on automatic boundary pauses. iOS can throttle web timers after the app is backgrounded or the screen locks.
